# html-book

## 提供するもの

| ファイル | 役割 |
|---|---|
| `html_book.py` | 入力 HTML を読み、本の形の HTML を別ファイルに書き出す。入力は書き換えない |

## 呼び出し方

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/skills/html-book/html_book.py report.html report-book.html
```

`CLAUDE_PLUGIN_ROOT` はこのプラグインがインストールされたディレクトリを指す。手動で実行するときの実パスは `claude plugin list --json` で確認するか、`find ~/.claude/plugins -path '*/html-book/skills/html-book/html_book.py'` で探す。

元のレポートを直したら、同じコマンドをもう一度実行すれば本の形にも反映される。BudouX（`budoux-html`）をかけた HTML を入力にすると、`<wbr>` と改行用 CSS もそのまま引き継がれる。

## ページの切り方

- `<main>` 直下の `<h2>` と `<h3>` ごとに新しいページを始める
- `<h2>` の直後に `<h3>` が来るまでの要素（章の導入、凡例など）は、最初の `<h3>` と同じページに入れる
- `<h3>` を持たない章は章全体で 1 ページ
- 最初の `<h2>` より前の要素と `<header>` の h1・p は表紙に載せる
- 入れ子の `<h3>`（カードの中の見出しなど）では切らない。直下の要素だけを数えている

## 挙動と罠

- ページの重ね順は z-index で決める。めくったページは左端を軸に `rotateY(-100deg)` で回し、回り終わる直前（0.5 秒後）に透明にする。最初から opacity を同時に変えると、めくるより「消える」に見える
- 影はめくり中の現在ページだけに付ける。全ページに `box-shadow` を付けると、重なった枚数分だけ周りが暗くなる
- 1 ページに収まらない内容はページの中でスクロールする。続きがあるときは下端をフェードさせ、フッターに「下に続きがあります」を出す。scroll と resize で判定し直す
- 目次を `<ol>` にすると、見出し自体の番号（「1. 結論」）と二重になる。`<ul>` で list-style を消している
- ←→ キーはページ送りに使うので、横に広い表の横スクロールはトラックパッドかスクロールバーで行う
- URL の `#p3` で 3 ページ目を直接開ける。ページを移るたびに `history.replaceState` で更新する
- 印刷時は全ページを縦に並べ、1 節ごとに改ページする
- `prefers-reduced-motion` のときはアニメーションを切る

## 依存

- Python 3.10 以上（標準ライブラリのみ）
