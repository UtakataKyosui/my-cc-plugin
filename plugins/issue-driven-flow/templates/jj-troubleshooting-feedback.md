# jj トラブル時の自己フィードバック

jj コマンドが失敗した場合、以下の手順でフィードバックループを回す。

## 手順

1. エラー原因を特定する
2. 同様の失敗を将来防ぐ knowledge として以下のいずれかに記録する:
   - **プロジェクト固有の教訓**: `.claude/rules/jj-learned.md` に追記（CLAUDE.md から参照済み）
   - **ユーザー横断の教訓**: auto memory に `feedback_jj_*.md` として保存（MEMORY.md にエントリ追加）
3. 重複があれば既存エントリを更新（新規作成しない）

## 記録すべき例

- 想定外のエラーメッセージと解決手順
- jj コマンドのバージョン差異による挙動の違い
- lefthook / fix.tools との連携で躓いたポイント
- conflict 解消時の非自明な操作手順
- スコープ違反の対処パターン

## 記録しない例

- 一度きりの typo（`jj sttus` → `jj status`）
- ドキュメントを読めば即座にわかる一般的な用法

## .claude/rules/jj-learned.md の形式

```markdown
# jj 学習済みパターン

## <エラーの概要>

**状況**: <どんなコマンドを実行したか>
**エラー**: <エラーメッセージ>
**原因**: <なぜ起きたか>
**解決**: <どう解決したか>
```
