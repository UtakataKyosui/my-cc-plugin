# test-guarantee

既存テストの実効性を監査するプラグイン。カバレッジが通っているのに壊れた、という状況を扱う。

## 構成

| 種別 | 名前 | 役割 |
|---|---|---|
| Skill | `test-guarantee:test-guarantee-audit` | 保証内容をアサーションから導く監査手順 |
| Agent | `test-guarantee-auditor` | 監査を委譲する読み取り専用エージェント。未保証の箇所には反例を添える |

## 使いどころ

- リファクタリングの前に安全網が足りているかを確かめたいとき
- PR で追加されたテストが名前どおりのことを保証しているか知りたいとき

テストケースの洗い出しは `issue-driven-flow` の `tdd-enforce` 系スキルを使う。このプラグインは既存テストの監査だけを扱う。
