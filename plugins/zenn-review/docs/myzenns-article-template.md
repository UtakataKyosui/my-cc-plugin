# MyZenns記事Issueの連携項目

`zenn-review:create-myzenns-issue`は、MyZennsのIssueテンプレートと次の項目を同期する。テンプレートが更新された場合は、この表とコマンドを同じPRで更新する。

| 項目 | 必須 | 内容 |
| --- | --- | --- |
| タイトル（仮） | はい | Issueタイトルと記事タイトル案 |
| 概要 | はい | 記事で伝える内容と目的 |
| 対象読者 | はい | 読者が前提として持つ知識 |
| アウトライン | はい | セクションの順序と各節の主張 |
| 参考資料・リンク | いいえ | 調査資料、公式ドキュメント、検証コード |
| 素材の所在 | はい | SessionSummary、Vault、下書きのパス |
| レビュー結果 | はい | 構文、文章、技術内容の確認結果 |
| 進行タスク | はい | MyZennsテンプレートのチェックリスト |

Issueを作成する前に、ユーザーが下書きとレビュー結果を確認して了承したことを会話上で確認する。
